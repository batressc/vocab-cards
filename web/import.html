Volver a las tarjetas

Administración

Configura la creación con IA y gestiona la carga de datos en un solo lugar.

Clave de administración

Se guarda solo en este navegador. Define ADMIN_TOKEN en el archivo .env del servidor.

Modelo predeterminado

Elige entre los modelos visibles. Este valor se comparte con todos los navegadores.

En el cuadro de creación puedes elegir temporalmente otro modelo visible.

Catálogo completo

Decide qué modelos aparecen para crear tarjetas y clasifícalos según su uso recomendado.

Los cambios no se comparten hasta que los guardes.

Tarjetas guardadas

Busca y selecciona una tarjeta para editarla con IA o eliminarla.

Editar tarjeta con IA

La tarjeta actual se carga desde el servidor. La IA puede cambiar head e id. Usa <<...>> para señalar una unidad semántica completa.
